# Dataset Notes

## Important
This repository does **not** include the original full SAR datasets.

## Why
- The datasets may be large
- Access conditions may apply
- Keeping the repository lightweight is better for public sharing

## Recommended Practice
Document:
- Original data source
- Download method
- Preprocessing pipeline
- Folder structure expected by the code

## Expected Local Structure

```text
data/
├── flipped/
│   ├── input/
│   └── output/
└── classification/
    ├── mountain/
    ├── sand/
    └── sea/
```
